## 阶梯计费：按整次请求落档，而不是分段累进

百炼部分模型按单次请求的输入 Token 总量分档，一次请求里的所有 Token 都按该档单价结算。举例：qwen3-max 输入 100K Token，落在 32K–128K 区间，这 100K 全部按第二档单价结算，前面的 32K 并不会按第一档算便宜。区间里的 K 代表 1,000，M 代表 1,000,000；输入落在哪一档，该档对应的输出单价也一起生效。

这个规则有个容易被忽略的推论：把长任务切块有时反而省钱。仍以新加坡地域 qwen3-max 为例，一次输入 100K，输入侧成本约 0.24 美元（0.1M × $2.4）；拆成四次各 25K 的请求，每次都落在第一档，合计约 0.12 美元（0.1M × $1.2），输入侧直接省一半。切块会增加请求次数和工程复杂度，是否值得拆，看你的场景再定。

## FAQ：关于阿里云大模型 Token 价格的高频疑问

**输入和输出是一个价吗？**
不是一个价。千问模型输入、输出分开计价，输出单价普遍是输入的 2–6 倍；思考模式的思维链与回答一并计入输出。

**免费额度所有地域都有吗？**
只有新加坡地域有。每款表格内模型 100 万 Token，有效期自开通百炼、模型发布或申请通过之日起 90 天（以较晚者为准），其他地域无免费额度。

**Batch 半价和上下文缓存折扣能叠加吗？**
不能同时生效，只能选其一。Batch 对输入输出都打 5 折，缓存只对输入有折扣（命中按 10% 计费）；批量离线任务选 Batch，重复前缀多的高频调用选缓存。

**Token Plan 不想用了能退款吗？**
不能。Token Plan 采用包月订阅制，官方说明不支持退款，订阅前按实际月用量估算需要的档位。

**夜间折扣需要手动开启吗？**
不需要。每晚 22:00 至次日 8:00 调用指定模型自动匹配 Night Plan 折扣，非指定时段或非指定模型恢复常规计费。
